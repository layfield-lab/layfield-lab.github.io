Software

Tools we build and share

Lab software is open source under the MIT license and lives at github.com/layfield-lab. Issues and pull requests are welcome.

biochar

Biochar-Simulator: builds realistic biochar structures from carbon count, H/C and O/C ratios, defects, functional groups and pore geometry, and writes GROMACS-ready OPLS-AA files.

pip install biochar
GitHubDocumentationPyPIconda-forge

biochar-pfas

Sets up molecular dynamics of PFOA, PFOS and PFBS on biochar surfaces built with Biochar-Simulator. It writes the files; you run them on your cluster.

GitHub

Mössbauer-DFT

A command-line and browser app that plans, generates and analyzes ORCA calculations and predicts ⁵⁷Fe Mössbauer parameters against a calibration set, with prediction intervals.

uv tool install --python 3.12 ./mossbauer_dft-0.6.1-py3-none-any.whl
GitHubReleases

fes-explore

Finds minima on PLUMED two-dimensional free-energy surfaces, assigns trajectory frames to basins and extracts a trajectory for each basin.

GitHub

pes-builder

Turns Gaussian outputs into potential energy surface diagrams, including reaction paths traced by intrinsic reaction coordinate calculations.

GitHub

ion-transfer-cv

Collective variables for ion transfer across liquid/liquid interfaces (the Karnes–Benjamin water-finger and solvation coordinates) for GROMACS and PLUMED.

GitHub

gromacs-mcp

A Model Context Protocol server that lets AI coding assistants run GROMACS setup, equilibration, production and analysis steps.

GitHub

chem-lab-tutorials

Colab notebooks for learning computational chemistry: Python for chemists, Gaussian output, trajectory analysis with MDAnalysis, PLUMED and OPES, and machine-learned collective variables.
