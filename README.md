# layfield-lab.github.io

Public website for the Layfield Lab (computational chemistry, University of St. Thomas).

- Edit page content in `pages/*.html` and styles in `assets/site.css`.
- Run `python3 build.py` to regenerate the top-level `*.html` files with the shared header and footer.
- While the `DRAFT` file exists, every page shows a "Draft for review" banner. Delete `DRAFT` and rebuild before publishing.
- Keep internal material off this site: funding, lab log, unpublished numbers, cluster details, and student names or positions without their consent.
